📋 Form Manager

Smart form management and intelligent email notifications for Google Sheets

Overview

Form Manager is a powerful Google Workspace add-on that streamlines form management and provides intelligent email notifications for new form responses. Designed for internal deployment within your organization.

Key Features

🚀

Quick Form Creation

  • Create Google Forms directly from your spreadsheet
  • Instant form link generation (2-3 seconds)
  • Automatic sheet creation and renaming
📧

Smart Notifications

  • No-reply email alerts for new responses
  • Configurable intervals (5min to 24hr)
  • Time window controls (business hours)
  • Beautiful HTML email formatting
⚙️

Flexible Configuration

  • Per-form notification settings
  • Multiple notification intervals
  • Manual "Send Now" button
  • Visual bell icon status indicators
🎯

Intelligent Tracking

  • Only notifies about NEW entries
  • JSON-based entry comparison
  • Prevents duplicate notifications
  • Per-sheet timestamp tracking
👥

Multi-User Support

  • Global tick system (single trigger)
  • No permission conflicts
  • Any user can enable/disable
  • Consistent email delivery
⏰

Smart Scheduling

  • Notifications aligned to interval boundaries
  • 24hr interval at configured start hour
  • Respects time windows
  • Efficient single-trigger architecture

How It Works

1. Create a Form

Open the Form Manager sidebar, enter a form name, and click "Create Linked Form". Your form is ready in seconds!

2. Configure Notifications

Add email recipients, choose your notification interval (5min, 15min, 30min, 1hr, 2hr, or 24hr), and set your time window.

3. Enable & Relax

Toggle notifications ON and let Form Manager handle the rest. You'll receive beautiful HTML emails whenever new responses arrive.

Notification Intervals

All notifications are aligned to interval boundaries starting from your configured start hour:

  • 5min - Every 5 minutes (e.g., 9:00, 9:05, 9:10...)
  • 15min - Every 15 minutes (e.g., 9:00, 9:15, 9:30...)
  • 30min - Every 30 minutes (e.g., 9:00, 9:30, 10:00...)
  • 1hr - Every hour (e.g., 9:00, 10:00, 11:00...) - recommended
  • 2hr - Every 2 hours (e.g., 8:00, 10:00, 12:00...)
  • 24hr - Once per day at start hour (e.g., always at 9:00 AM)

Getting Started

  1. Install the Form Manager add-on
  2. Open any Google Sheet
  3. Click Form Manager in the menu bar
  4. Click Open Form Manager
  5. Start creating forms and setting up notifications!
